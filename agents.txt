# AkinSec

> Agent discovery for AkinSec / AskAkin. Canonical LLM index: llms.txt. Expanded doc map: llms-full.txt. Human/agent brief: AI.md.

AkinSec is a cyber operations / security company. Its product surface is AI-driven security ops tooling—not a consumer chat toy. AskAkin is the hosted AI workspace for security operations: SIEM/EDR posture, identity threats, agents, and tools that behave like infrastructure. Positioning on the marketing site: Initiate, Contain, Execute. Audience: businesses that need SOC-adjacent security ops capacity without standing up a full stack alone.

## What it is

- **AkinSec** — company / platform brand. Builds AI-operated security infrastructure for businesses.
- **AskAkin** — the application: multi-tenant security workspace with multi-provider AI chat, agents, skills, MCP, and a live SIEM surface. Production: https://app.akinsec.com
- **Security Engine** — dedicated Wazuh-based detection stack (manager + indexer + authenticated gateway). v1 is provisioned per user; org-shared stacks are proposed.
- **Cloud Tools** — proposed isolated analyst workstations (web testing, packet analysis, reverse engineering), scope-bound and AI-controllable. Not a live SKU.

This repository (`dfalt0/akinsec-public`) is public architecture and product documentation. Application source is private.

## Products (shipped vs not)

- Shipped: AskAkin workspace, multi-provider AI, agents/skills/MCP/RAG, Security Engine (gateway-only SIEM ingress), WorkOS/OIDC tenancy, org-scoped code interpreter.
- Partial: classic public agent enrollment; payment processor / live subscriptions.
- Proposed: org-shared SIEM + seat RBAC; Cloud Tools labs (ZAP/Wireshark/Ghidra defaults; commercial BYOL).
- Explicitly not shipped: Wazuh Dashboard as UI (AskAkin is the UI).

## What not to confuse it with

- Not a generic ChatGPT wrapper or consumer chatbot brand.
- Not LibreChat itself—LibreChat is an upstream patch source; AskAkin is the product brand and SIEM/ops overlay.
- Not Wazuh Dashboard, not “Wazuh as a public SaaS UI.”
- Not an open-source application clone-and-run; this repo is docs only.
- Not a pentest-anyone platform; use is defending / authorized testing of systems the customer owns or has written permission to test.
- Do not describe Cloud Tools (Burp/IDA/etc.) as shipped SKUs.
- Do not invent private admin, billing console, or internal API routes.
